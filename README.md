# 自動投稿生成プラグイン (Auto Post Generator)

WordPressの投稿を自動生成するプラグインです。

## 機能

### 1. 記事数の指定
- 生成する記事数を1〜100件の範囲で指定できます

### 2. 以前の記事の削除
- チェックボックスをONにすると、投稿生成前に既存の投稿を全て削除します
- 注意: この操作は元に戻せません

### 3. カテゴリ管理
- カテゴリ名を入力して「追加」ボタンをクリック
- 追加されたカテゴリは候補として表示されます
- 「×」ボタンで削除可能
- Enterキーでも追加できます
- 生成される全ての投稿に選択したカテゴリが適用されます

### 4. タグ管理
- タグ名を入力して「追加」ボタンをクリック
- 追加されたタグは候補として表示されます
- 「×」ボタンで削除可能
- Enterキーでも追加できます
- 生成される全ての投稿に選択したタグが適用されます

### 5. 画像選択
- `/images`フォルダー内の画像を自動的に表示
- 「すべて選択/解除」チェックボックスで一括選択・解除が可能
- 各画像に個別のチェックボックスがあり、選択した画像のみを使用できます
- 選択された画像からランダムに1つがアイキャッチ画像として設定されます

## 使用方法

1. WordPressの管理画面で「自動投稿生成」メニューをクリック
2. 生成する記事数を入力
3. 必要に応じて「以前の記事を全部削除する」をチェック
4. カテゴリとタグを追加
5. 使用したい画像を選択
6. 「投稿生成」ボタンをクリック

## ファイル構成

```
autopostgen/
├── autogenpost.php     # メインプラグインファイル
├── admin-page.php      # 管理画面のHTML
├── README.md           # このファイル
├── css/
│   ├── style.scss      # スタイルシート（SCSS）
│   └── style.css       # コンパイル済みCSS
├── js/
│   └── autopostgen.js  # JavaScript（カテゴリ・タグ・画像管理）
└── images/             # 画像フォルダー
    ├── *.jpg
    ├── *.png
    └── ...
```

## 技術仕様

- WordPress 5.0以上
- PHP 7.0以上
- セキュリティ: Nonce検証を実装
- パフォーマンス: 大量投稿時の負荷軽減のため0.1秒の待機時間を設定

## 注意事項

- 画像は`/images`フォルダーに配置してください
- 対応画像形式: jpg, jpeg, png, gif, webp
- 最大100件まで一度に生成可能
- 「以前の記事の削除」は全ての投稿を削除するため、本番環境での使用には注意が必要です

## 開発者向け

### SCSS のコンパイル

```bash
npx sass css/style.scss css/style.css
```

### カスタマイズ

投稿の内容は`autopostgen_generate_content()`関数で生成されます。
この関数を編集することで、生成される投稿の内容をカスタマイズできます。
